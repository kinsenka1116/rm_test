# 前哨站整体旋转状态估计与滤波

## 一、题目

给定一段前哨站旋转视频，按帧检测装甲板并进行 PnP 位姿解算。根据多帧观测，输出**前哨站的三维旋转中心、旋转角和角速度**。当画面中的主要观测从一块装甲板换到另一块时，仍须使用同一个旋转角定义。

另外，对**同一块装甲板中心到相机光心的直线距离**做一维滤波。该距离是本题唯一单独考查滤波的量，状态估计可以联合使用多帧观测。

前阶段解决的是单帧装甲板检测和位姿解算。本题新增跨帧关联、前哨站旋转状态估计和距离滤波，可以复用前一阶段的检测与 PnP 代码。

程序只读视频文件，可以慢于视频帧率。处理第 `k` 帧时，状态估计、板号关联和距离滤波仅能使用第 `k` 帧及之前的观测，不得在视频结束后回填早先的结果。滤波测试序列由程序生成。

## 二、输入与观测

使用随题目提供的 `outpost.avi`。原始画面为 1280 × 1024 像素，参考帧率为 119.997728 FPS，参考帧数为 4210。依次处理全部可解码的帧，第一帧记为 `frame_id = 0`，视频时间为 `time_s = frame_id / fps`。优先使用视频读取到的有效帧率；若读取不到有效帧率，使用参考帧率并在运行记录中注明。参考帧数只用于检查文件是否读对；统计和屏蔽均以实际解码帧号为准。不要用程序运行耗时计算角速度。

本题使用下列相机参数与当前视频配套。畸变系数顺序为 `[k1, k2, p1, p2, k3]`；如果检测在裁切或缩放后的图像上进行，先将角点换回原图像素坐标，再使用这组参数。

```text
K = [[1781.053454, 0, 510.5751561],
     [0, 1781.686873, 472.9735763],
     [0, 0, 1]]
D = [-0.04420740074, -0.1081537096,
     -0.0006506219039, 0.0002357380215, 0.466737247]
```

装甲板模型原点为装甲板中心，宽 `w = 0.135 m`、高 `h = 0.056 m`；模型 x 轴沿宽度向右，y 轴沿高度向下。角点名称按装甲板自身的局部方向定义；检测器输出的四个图像角点必须与以下模型点一一对应：

```text
左上 (-w/2, -h/2, 0)；右上 (w/2, -h/2, 0)；
右下 ( w/2,  h/2, 0)；左下 (-w/2, h/2, 0)。
```

所有三维位置使用 OpenCV 相机坐标系：原点为相机光心，X 轴向图像右方，Y 轴向图像下方，Z 轴指向相机前方，长度单位为米。PnP 平移向量 `tvec = (tx, ty, tz)` 表示装甲板中心位置；`distance_raw_m = sqrt(tx² + ty² + tz²)` 是其到相机光心的直线距离，`tz` 是 Z 方向深度。旋转中心 `C` 由多帧 PnP 位置拟合得到，三个分量均使用该相机坐标系表示。

PnP 解算成功、结果均为有限数且 `tz > 0` 时，记录位姿和距离。重投影误差为四角点误差的平均欧氏像素距离。可以增加测量质量筛选；筛选规则及阈值写入说明，并在正常和屏蔽运行中保持一致。统一使用本节给出的相机参数。

## 三、旋转状态的统一定义

按固定相机和固定旋转轴建模。三块装甲板绕同一轴旋转，半径均为 `R = 0.275 m`，沿旋转轴方向分别位于三个轴向层级，相邻板的相位相隔 `2π/3`。本视频按恒角速度模型估计；角速度大小与方向由当前及历史观测得到，不预先给定。每次状态更新使用当时可用的当前及历史观测拟合 `theta(t) = theta0 + omega * (t - t0)`，其中 `t0` 为本次拟合窗口起始时刻，`theta0` 为该时刻的相位，`omega` 为本次拟合得到的角速度。新观测到来后可以更新拟合参数；`states.csv` 每行填写该帧的角速度估计值。`segment_id` 表示相位连续的估计段，不表示段内各帧参数数值完全相同。

| 输出量                         | 定义                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 旋转中心 `C = (C_x, C_y, C_z)` | 旋转轴与中间轴向层级装甲板中心圆轨迹所在平面的交点。三个分量均为相机坐标系下相对于相机光心的位置，单位为 m；`C_y` 沿相机 Y 轴向下为正。 |
| 旋转角 `theta`                 | 中间轴向层级装甲板的径向方向相对指定零方向的有符号角度，连续展开，单位为 rad。即便当前只观测到其他轴向层级，也输出中间层级所对应的角度。 |
| 角速度 `omega`                 | 上述旋转角对视频时间的变化率，带正负号，单位为 rad/s。       |

用单位向量 `a` 表示旋转轴方向。按 `a_y`、`a_x`、`a_z` 的顺序检查分量，第一个绝对值大于 `1e-6` 的分量取负，以固定轴向正负。将相机正 X 方向投影到垂直于 `a` 的平面并归一化，得到零角方向 `e0`；若投影长度小于 `1e-6`，改用相机正 Z 方向投影。令 `e90 = a × e0`，从 `e0` 转向 `e90` 为正方向。旋转轴由本次观测估计。

按沿 `a` 的轴向位置定义三块物理装甲板的 `plate_id`：`minus`、`middle`、`plus`，分别表示负向层级、中间层级和正向层级；这些名称只表示沿约定轴 `a` 的坐标，不表示重力方向上的下、中、上。其轴向偏移由题目给定；中间层级作为相位参考。负向和正向层级的相位符号对应关系未给定，见下表：

| `plate_id` |      `h_i` |                         `delta_i` |
| ---------- | ---------: | --------------------------------: |
| `minus`    | `−0.102 m` |                       `±2π/3 rad` |
| `middle`   |      `0 m` |                           `0 rad` |
| `plus`     | `+0.102 m` | 与 `minus` 符号相反的 `∓2π/3 rad` |

根据本帧及此前观测判断候选的 `plate_id`。候选三维位置在拟合轴上的投影相对中间层级的位置决定板号；无法确认时填 `unknown`。同一帧内，同一物理板有多个候选通过相应质量检查时，状态估计和距离滤波分别选重投影误差最小的候选；误差相同时取 `candidate_id` 较小者。

对表中两种正负相位映射，使用相同的初始化观测集合分别拟合模型。每种映射都使用恒角速度模型 `theta(t) = theta0 + omega * (t - t0)`，拟合 `C`、`a`、`theta0` 和 `omega`；两种拟合仅改变 `minus`、`plus` 的相位偏移符号。记第 `k` 个参与拟合的观测位置为 `p_k`，所属层级为 `i_k`、观测时间为 `t_k`，该观测的模型预测位置为 `P_{i_k}(t_k)`。位置残差按 `RMSE = sqrt(sum(||p_k - P_{i_k}(t_k)||²) / N)` 计算，`N` 为参与拟合的观测数。

仅当 `RMSE_min < RMSE_max` 且 `RMSE_min <= 0.9 * RMSE_max` 时，选用较小 RMSE 对应的映射；否则继续初始化或标记为关联不确定。映射选定后在本次视频运行中保持不变。说明中列出两种映射的 RMSE 和观测数。旋转中心、旋转轴、旋转角和角速度由本次视频观测估计；半径及轴向间隔使用题目给定值。

在上述定义下，第 `i` 块板的中心由下式描述：

```text
P_i = C + h_i * a
        + R * [e0 * cos(theta + delta_i) + e90 * sin(theta + delta_i)]
```

对属于第 `i` 层的观测位置 `p_k`，其径向角为 `phi_k = atan2((p_k - C) · e90, (p_k - C) · e0)`；换算到中间层级的旋转角为 `theta_k = unwrap(phi_k - delta_i)`。`unwrap` 表示在时间顺序上加减 `2π`，使同一估计段内角度连续。

首次输出 `valid` 状态前，拟合数据须满足：三个轴向层级各有至少 10 个通过质量检查的 PnP 观测；每层连续相位跨度不少于 90°；拟合时间跨度不少于 0.5 s；两种相位映射满足前述选择条件。相位跨度按该层已展开相位的最大值减最小值计算。条件未满足时输出 `initializing`。首个有效估计段的 `segment_id` 为 0；每个新估计段的首个有效状态 `theta` 取 `[-π, π)`，同一段后续角度连续展开。短时缺少观测但角度可接续时沿用原 `segment_id`；重新初始化时 `segment_id` 加 1。说明中列出估计窗口、参数更新方法和角速度计算方法。

随后用同一视频、同一配置再跑一次：令 `1200 <= frame_id < 1260` 的 60 帧在进入关联、状态估计和距离滤波之前没有可用观测。原帧号和视频时间不变；这些帧的状态标为 `masked`。这是程序正确性检查：60 帧均须标记为 `masked`，程序不得中止。另报告恢复表现：分别列出屏蔽运行和未屏蔽基准运行在 `frame_id >= 1260` 后的首个有效帧；报告屏蔽运行从 1260 帧至首个有效帧的时间差，以及恢复时的 `segment_id` 是否与屏蔽前相同。未恢复时填 `未恢复`。提交两次运行在第 1080 至 1379 帧的逐帧状态对照。恢复时长和是否沿用原段作为方案比较项；评价恢复表现时，以未屏蔽基准运行确认该处原视频是否本来就有可用观测。

### 2. 距离滤波

按物理板号分别维护滤波状态，至少给出一块板在视频中的原始距离和滤波距离曲线。只使用当前及此前的距离样本；其它装甲板的斜距不能接入同一条距离序列。没有可用测量时滤波输出留空；再次获得测量时，可继续同一块板的滤波状态或按已说明的间隔阈值重新初始化。换板前后真实距离允许不同。结合帧号与板号说明视频中的一处明显跳变或大变化，区分换板、解算异常和同一块板在旋转中的距离变化；证据不足时注明。

用**同一种滤波算法**执行下面的定量测试。参数允许因采样率不同而调整，分别列出视频和测试的配置。测试程序仅将 `time_s` 和 `observed_m` 传给滤波器，`reference_m` 仅用于计算指标。每条测试序列从空滤波状态开始，首个输出按所选算法的初始化规则产生；初始化规则须在说明中给出。滤波规则对所有采样点相同，不得按题目给出的异常点或阶跃时刻编写单独规则。

```text
n = 0, 1, ..., 600；t = n / 100 秒
reference_m = 2.50（n < 200），否则为 3.00
observed_m  = reference_m + 0.02*sin(6πt) + 0.01*sin(34πt)
仅在 n = 150 时，将 observed_m 额外增加 0.40 m
```

输出全部 601 个 `filtered_m`，并报告：

| 指标                      | 计算范围与方法                                               |
| ------------------------- | ------------------------------------------------------------ |
| 稳定段平均绝对误差（MAE） | 分别在 `n = 0…99` 和 `n = 300…399` 内计算。对原始和滤波序列分别取与参考值的绝对误差，再求该段平均，单位为 m。 |
| 异常点误差                | 在 `n = 150` 比较原始与滤波序列相对参考值的绝对误差，单位为 m。 |
| 阶跃响应延迟              | 从 `n = 200` 开始，找第一个使 `n、n+1、n+2` 的滤波值均满足 `abs(filtered_m - 3.00) <= 0.05` 的 `n`。延迟为 `(n - 200) / 100` 秒；采样结束仍不满足时填“未达到”。 |

定量测试的基本要求：两段稳定段 MAE 和异常点误差均低于原始序列，阶跃响应延迟不超过 0.25 s。这里的“低于原始序列”是指两段稳定区间的 MAE 分别低于对应区间原始 MAE，异常点绝对误差低于原始异常点绝对误差。解释算法和参数对这三项指标的影响。

提交正常运行和屏蔽运行的输出、滤波测试数据、验证要求中的统计结果与图表，以及用于展示角点和模型投影的示例帧。两次视频运行的输出分别保存；保留滤波测试数据和生成入口。

CSV 首行为字段名。以下字段为最低要求，可增加诊断字段。空值用空单元格表示；标志字段使用 `0` 或 `1`；`candidate_id` 从 0 开始，且只在当前帧内有效。

| 文件 | 一行对应什么 | 字段 |
| --- | --- | --- |
| `observations.csv` | 一帧中的一个装甲板候选；没有候选的帧无需占行。 | `frame_id,time_s,candidate_id,corner0_u_px,corner0_v_px,corner1_u_px,corner1_v_px,corner2_u_px,corner2_v_px,corner3_u_px,corner3_v_px,center_u_px,center_v_px,plate_id,pnp_valid,tvec_x_m,tvec_y_m,tvec_z_m,reprojection_error_px,used_for_state,used_for_distance_filter,distance_raw_m,distance_filtered_m,reason` |
| `states.csv` | 每个解码帧恰好一行，包括无效帧。 | `frame_id,time_s,state_status,segment_id,primary_plate_id,rotation_center_x_m,rotation_center_y_m,rotation_center_z_m,axis_x,axis_y,axis_z,theta_rad,omega_rad_s` |
| `filter_test.csv` | 人工序列中的一个采样点，按 `n` 递增。 | `n,time_s,reference_m,observed_m,filtered_m` |

- `corner0` 至 `corner3` 依次为左上、右上、右下、左下角点，使用原图像素坐标；中心坐标为四角点坐标的算术平均值。每帧内按 `center_u_px`、再按 `center_v_px` 递增为候选编号；中心坐标相同时按检测器输出顺序编号。
- `plate_id` 使用 `minus`、`middle`、`plus` 或 `unknown`。`pnp_valid=0` 时，`tvec`、重投影误差和距离字段留空；PnP 有效但被质量规则拒绝时，`pnp_valid=1`，保留原始测量并在 `reason` 中注明原因。
- `used_for_state=1` 表示该候选参与状态估计；`used_for_distance_filter=1` 表示该候选进入对应物理板的距离滤波。同一帧同一物理板最多一个候选用于状态估计，最多一个用于距离滤波。无法确认板号、PnP 失败、测量被拒绝或未进入滤波时，`distance_filtered_m` 留空。屏蔽帧不写候选记录。
- `primary_plate_id` 按视频状态估计部分的定义填写；状态无效时留空。`state_status` 只能为 `valid`、`initializing`、`no_observation`、`association_uncertain` 或 `masked`。人工屏蔽帧标记为 `masked`；本帧没有通过 PnP 有效性和质量检查的候选时为 `no_observation`；有通过检查的候选但没有候选能确认板号或接续角度时为 `association_uncertain`；有候选成功关联但模型初始化条件未满足时为 `initializing`；满足模型条件且至少一个关联观测参与状态估计、能够输出全部状态量时为 `valid`。同帧同时有已关联和未关联候选时，只要已关联候选足以输出状态，就标记为 `valid`。
- 状态无效时，`segment_id` 及其后的数值字段留空；仅 `valid` 行填写完整状态。`rotation_center_*` 为旋转中心的相机坐标分量；`axis_*` 为旋转轴单位向量分量。所有三维位置和距离单位为 m，图像坐标及重投影误差单位为 px，角度单位为 rad，角速度单位为 rad/s。

## 六、其他

方案比较关注换板时的角度连续性、有效状态覆盖、屏蔽后的恢复表现，以及距离滤波在稳定段误差、异常点误差和响应延迟之间的取舍。除滤波定量门槛和规定的屏蔽检查外，视频状态估计质量按提交的覆盖率、模型残差和换板实例进行比较。
