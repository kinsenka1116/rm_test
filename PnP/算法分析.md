###  单因素敏感性实验
***
**移动角点（右下角角点向右下各移动10像素）：**
测试对象：test_1.png

|     | tz                 | distance          | reprojection_error |
| --- | ------------------ | ----------------- | ------------------ |
| 扰动前 | 2.4876020993544286 | 2.508636216157184 | 0.7071067811865476 |
| 扰动后 | 2.3715259411802245 | 2.392219194388714 | 3.5355339059327378 |
- 结论：
- 1. 角点位置影响reprojection_error，原因推测是角点只有单侧不成比例的移动改变了物理坐标系的单位长度，导致PnP输入的aim_points（单位：像素），与objectPoints（单位：m）比例水平竖直不对应，预计如果每个角点都成比例移动的话不会影响reprojection_error
- 2. 物理尺寸不变的情况下，目标像素变大，距离减小
***
**模型宽度增加10%**
测试对象：test_2.png

|     | tz                 | distance           | reprojection_error |
| --- | ------------------ | ------------------ | ------------------ |
| 扰动前 | 2.615554772797421  | 2.6528272390142087 | 1.4571067811865475 |
| 扰动后 | 2.8303171782713643 | 2.87071115745505   | 1.4571067811865475 |
- 结论：
- 1. 模型宽度不影响reprojection_error，影响平移矩阵
- 2. 像素不变的情况下，目标物理尺寸变大，距离变大

***
**水平竖直焦距变为原来的2倍**
测试对象：test_3.png

|     | tz                 | distance          | reprojection_error |
| --- | ------------------ | ----------------- | ------------------ |

| 扰动后 | 4.9959706051560975 | 5.005942493456479 | 1.0                |
- 结论：
- 1. 焦距不影响reprojection_error
- 2. 像素，物理尺寸不变的情况下，焦距越大，距离越大

### 区分规则
1. reprojection_error<=5 
	原因：重投影和实际检测到的矩形框的平均像素距离过大,选择5是因为csv中基本看不到大于5的（有点结果推过程了...）
	由单因素影响试验得出，三个因素中只有角点不成比例移动影响reprojection_error，其余对reprojection_error均无影响，因此这个规则适用所有大小与物理尺寸的物体（前提是OpenCV检测的角点位置与实际位置误差较小）
	错报或漏报：无
2. tz>0
	原因：目标不在相机前方，本视频中原点在目标中心，必然有tz>0
	错报或漏报：物理世界建立的坐标系的原点不在相机前方
3. abs(Z_rough-tz)/min(Z_rough,tz)<10
	原因：Z_rough估计深度与PnP估计深度数量级几乎相同,数量级不同估计PnP大概率有问题
	错报或漏报：物体在图片的边缘，并且距离极远，导致Z_rough与实际深度差距过大
